# 3. Граф переходов полученного МПА

Для языка

```math
L_5=\{a^3b^nc^n\mid n\ge0\}
```

построен автомат с магазинной памятью.

**Критерий принятия цепочек — по финальному состоянию.**

## Логика работы автомата

Состояния `q0`, `q1`, `q2`, `q3` контролируют наличие ровно трех начальных символов `a`.

При чтении каждого символа `b` автомат помещает в магазин символ `B`. При чтении каждого символа `c` один символ `B` извлекается из магазина. Когда все `B` удалены и на вершине остается маркер `Z`, автомат может перейти в финальное состояние `qf`.

Состояние `q3` также является финальным, поскольку при `n=0` цепочка `aaa` принадлежит языку.

## Программная реализация

В программе используется стек. На каждый символ `b` в него помещается `X`, а на каждый символ `c` один `X` удаляется. Цепочка принимается, если она начинается ровно с `aaa`, после этого имеет вид `b^n c^n`, весь вход прочитан и стек счетчиков пуст.
