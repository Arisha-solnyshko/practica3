# 7. Формальное доказательство принадлежности к классу КСЯ

## Вариант 5 части 3

Задан язык

```math
L_{37}=\{a^l b^k a^j b^n \mid n+j\le k+l\}
```

на алфавите `\{a,b\}`.

Необходимо формально определить, является ли язык контекстно-свободным.

## Доказательство

Язык **является контекстно-свободным**. Докажем это построением автомата с магазинной памятью.

Построим недетерминированный МПА

```math
P=(Q,\Sigma,\Gamma,\delta,q_0,Z,F),
```

где

```math
Q=\{q_0,q_1,q_2,q_3,q_f\},\qquad
\Sigma=\{a,b\},\qquad
\Gamma=\{X,Z\},\qquad
F=\{q_f\}.
```

Символ `Z` является маркером дна магазина, а `X` используется для подсчета символов.

### Идея работы МПА

Первые два блока `a^l b^k` образуют левую часть неравенства `k+l`. При чтении каждого символа из этих блоков автомат помещает в магазин один символ `X`. Поэтому после чтения `a^l b^k` в магазине находится

```math
X^{l+k}Z.
```

Следующие два блока `a^j b^n` образуют правую часть `j+n`. При чтении каждого символа из этих блоков автомат извлекает из магазина один `X`.

Если символов в последних двух блоках окажется больше, чем в первых двух, автомат попытается извлечь `X`, когда на вершине уже находится `Z`, и вычисление остановится без принятия.

Если же

```math
j+n\le l+k,
```

то всех символов `X` достаточно и после полного чтения входа автомат может перейти в заключительное состояние. При строгом неравенстве в магазине остаются лишние `X`; это допустимо, поскольку принятие выполняется **по финальному состоянию**.

### Переходы

Для `Y ∈ {X,Z}` функция переходов задается следующим образом:

```math
\delta(q_0,a,Y)=\{(q_0,XY)\},
```

```math
\delta(q_0,\lambda,Y)\ni(q_1,Y),
```

```math
\delta(q_1,b,Y)=\{(q_1,XY)\},
```

```math
\delta(q_1,\lambda,Y)\ni(q_2,Y),
```

```math
\delta(q_2,a,X)=\{(q_2,\lambda)\},
```

```math
\delta(q_2,\lambda,Y)\ni(q_3,Y),
```

```math
\delta(q_3,b,X)=\{(q_3,\lambda)\},
```

```math
\delta(q_3,\lambda,X)\ni(q_f,X),\qquad
\delta(q_3,\lambda,Z)\ni(q_f,Z).
```

Состояния имеют следующий смысл: `q0` читает первый блок `a^l`, `q1` — блок `b^k`, `q2` — блок `a^j`, `q3` — блок `b^n`, а `qf` является заключительным. Спонтанные `λ`-переходы позволяют автомату недетерминированно выбрать границы блоков, в том числе когда один из блоков пуст.


## Корректность построения

Пусть

```math
w=a^l b^k a^j b^n\in L_{37}.
```

После чтения первых двух блоков автомат записывает в магазин `l+k` символов `X`. Затем при чтении последних двух блоков он должен удалить `j+n` символов `X`. Так как по условию

```math
j+n\le k+l,
```

магазин не исчерпается раньше окончания входа, и после чтения всей цепочки автомат достигает `q_f`. Следовательно, каждая цепочка языка принимается МПА.

Обратно, если цепочка принимается построенным МПА, последовательность его состояний гарантирует форму

```math
a^l b^k a^j b^n.
```

За первые `l+k` символов в магазин помещается ровно `l+k` символов `X`, а последние `j+n` символов могут быть полностью прочитаны только при наличии достаточного количества `X`. Поэтому обязательно выполняется

```math
j+n\le l+k.
```

Следовательно, любая принятая цепочка принадлежит `L37`.

Таким образом,

```math
L(P)=L_{37},
```

то есть для языка существует автомат с магазинной памятью. Следовательно, **язык `L37` принадлежит классу контекстно-свободных языков**.
