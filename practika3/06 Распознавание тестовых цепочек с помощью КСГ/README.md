# 6. Распознавание тестовых цепочек с помощью КСГ

Для проверки грамматики использован **Brute Force Parse** в JFLAP.

## Допускаемая цепочка `aab`

Для `aab` выполняется `n_a=2`, `n_b=1`, поэтому количества символов различны и цепочка должна приниматься.

![Цепочка aab принята](<./01-aab-accept.png>)

## Недопускаемая цепочка `aabb`

Для `aabb` выполняется `n_a=2`, `n_b=2`, поэтому цепочка не принадлежит языку.

![Цепочка aabb отклонена](<./02-aabb-reject.png>)

Таким образом, результаты распознавания соответствуют условию `n_a(w) ≠ n_b(w)`.
