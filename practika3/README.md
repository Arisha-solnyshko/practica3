```math
L_{21}=\{w\in\{a,b\}^{*}\mid n_a(w)\ne n_b(w)\}.
```

### Часть 3

Формально исследовать язык

```math
L_{37}=\{a^l b^k a^j b^n\mid n+j\le k+l\}
```
