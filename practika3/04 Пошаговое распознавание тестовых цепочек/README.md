# 4. Пошаговое распознавание нескольких тестовых цепочек

Проверка автомата выполнена в JFLAP в пошаговом режиме с критерием принятия по финальному состоянию. На каждом кадре выделено текущее состояние автомата. В нижней части окна показаны непрочитанный остаток входной цепочки и содержимое магазина.

## 4.1 Допустимая цепочка `aaabc`

Цепочка имеет вид `a^3b^1c^1`, поэтому принадлежит языку `L_5` и должна быть принята.

**Шаг 0.** Начальная конфигурация: состояние `q0`, непрочитанная цепочка `aaabc`, в магазине находится маркер `Z`.

![Начальная конфигурация для aaabc](<./02-aaabc-step-0.png>)

**Шаг 1.** Прочитан первый символ `a`, автомат перешел в состояние `q1`.

![Первый шаг для aaabc](<./03-aaabc-step-1.png>)

**Шаг 2.** Прочитан второй символ `a`, автомат перешел в состояние `q2`.

![Второй шаг для aaabc](<./04-aaabc-step-2.png>)

**Шаг 3.** Прочитан третий символ `a`, автомат перешел в состояние `q3`. Во входной цепочке еще остаются символы `bc`, поэтому распознавание продолжается.

![Третий шаг для aaabc](<./05-aaabc-step-3.png>)

**Шаг 4.** Прочитан символ `b`, автомат перешел в `q4` и поместил символ `B` в магазин.

![Четвертый шаг для aaabc](<./06-aaabc-step-4.png>)

**Шаг 5.** Прочитан символ `c`, автомат перешел в `q5` и удалил один символ `B` из магазина. Вход прочитан полностью.

![Пятый шаг для aaabc](<./07-aaabc-step-5.png>)

**Шаг 6.** На вершине магазина находится `Z`, поэтому выполнен `λ`-переход в финальное состояние `qf`. Зеленая конфигурация означает, что цепочка принята.

![Цепочка aaabc принята](<./08-aaabc-step-6.png>)

## 4.2 Недопустимая цепочка `aaabbc`

После трех символов `a` цепочка содержит два символа `b` и только один символ `c`. Она не имеет вида `a^3b^nc^n` и должна быть отклонена.

**Шаг 0.** Начальная конфигурация: состояние `q0`, непрочитанная цепочка `aaabbc`.

![Начальная конфигурация для aaabbc](<./09-aaabbc-step-0.png>)

**Шаг 1.** Прочитан первый символ `a`, автомат находится в состоянии `q1`.

![Первый шаг для aaabbc](<./10-aaabbc-step-1.png>)

**Шаг 2.** Прочитан второй символ `a`, автомат находится в состоянии `q2`.

![Второй шаг для aaabbc](<./11-aaabbc-step-2.png>)

**Шаг 3.** Прочитан третий символ `a`, автомат находится в состоянии `q3`; непрочитанный остаток равен `bbc`.

![Третий шаг для aaabbc](<./12-aaabbc-step-3.png>)

**Шаг 4.** Прочитан первый символ `b`, в магазин помещен первый символ `B`.

![Четвертый шаг для aaabbc](<./13-aaabbc-step-4.png>)

**Шаг 5.** Прочитан второй символ `b`, в магазин помещен второй символ `B`.

![Пятый шаг для aaabbc](<./14-aaabbc-step-5.png>)

**Шаг 6.** Прочитан единственный символ `c`, один символ `B` удален из магазина. Вход закончился, но в магазине остался еще один символ `B`.

![Шестой шаг для aaabbc](<./15-aaabbc-step-6.png>)

**Шаг 7.** Переход из `q5` в `qf` невозможен, поскольку для него на вершине магазина должен находиться `Z`, а там остался `B`. Красная конфигурация означает, что цепочка отклонена.

![Цепочка aaabbc отклонена](<./16-aaabbc-step-7.png>)

## 4.3 Групповая проверка дополнительных цепочек

![Проверка нескольких цепочек](<./01-pda-multiple-run.png>)

| Цепочка | Результат | Обоснование |
|---|---|---|
| `aaabc` | Accept | Имеет вид `a^3b^1c^1` |
| `aaabbcc` | Accept | Имеет вид `a^3b^2c^2` |
| `aaccbb` | Reject | Нет трех начальных символов `a` и нарушен порядок блоков |
| `aa` | Reject | Нет трех начальных символов `a` |
