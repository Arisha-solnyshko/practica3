# 5. Полученная КСГ

Для языка

```math
L_{21}=\{w\in\{a,b\}^{*}\mid n_a(w)\ne n_b(w)\}
```

построена контекстно-свободная грамматика:

```text
S → A
S → B

A → EaE
A → EaA

B → EbE
B → EbB

E → aEbE
E → bEaE
E → λ
```

Смысл нетерминалов:

- `E` порождает цепочки с одинаковым количеством `a` и `b`;
- `A` порождает цепочки, в которых `a` больше, чем `b`;
- `B` порождает цепочки, в которых `b` больше, чем `a`;
- `S → A | B` задает все цепочки, для которых `n_a(w) ≠ n_b(w)`.
