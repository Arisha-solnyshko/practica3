# 2. Цель работы с постановкой задачи

**Цель работы** — изучить автоматы с магазинной памятью и контекстно-свободные грамматики, научиться строить МПА и КСГ в JFLAP, выполнять распознавание тестовых цепочек и формально исследовать принадлежность языка классу контекстно-свободных языков.

## Часть 1. Вариант 5

Задан язык

```math
L_5=\{a^3b^nc^n\mid n\ge0\}.
```

Необходимо построить в JFLAP автомат с магазинной памятью, распознающий язык, указать критерий принятия цепочек и предложить программную реализацию.

## Часть 2. Вариант 5

Задан язык

```math
L_{21}=\{w\in\{a,b\}^{*}\mid n_a(w)\ne n_b(w)\}.
```

Необходимо построить в JFLAP контекстно-свободную грамматику и проверить распознавание тестовых цепочек.

## Часть 3. Вариант 5

Задан язык:

```math
L_{37}=\{a^l b^k a^j b^n\mid n+j\le k+l\}
```

на алфавите `\{a,b\}`.

Необходимо формально доказать контекстно-свободность либо отсутствие контекстной свободы данного языка.
